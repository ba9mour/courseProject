## **Проектно-технологическая практика:**
#### **Консольный менеджер задач с графическим интерфейсом и сохранением в JSON**

Этот проект представляет собой простое приложение для управления задачами. Задачи хранятся в памяти (`std::vector<Task>`) и могут сохраняться/загружаться из файла `tasks.json` в формате JSON благодаря библиотеке [nlohmann/json](https://github.com/nlohmann/json). Над контейнером задач реализован класс-обёртка `TaskManager`, который предоставляет методы для добавления, удаления, редактирования, сортировки и сериализации задач.

В дополнение к консольному режиму, к проекту добавлён минимальный графический интерфейс на основе **Qt Widgets**. Пользователь может:

- Просматривать список всех задач
- Добавлять новую задачу (заголовок, описание, приоритет, дедлайн, статус)
- Удалять выделенную задачу
- Редактировать выбранную задачу
- Сохранять текущее состояние в `tasks.json`
- Загружать задачи из `tasks.json`

#### **Основные возможности**

1. **Класс `Task`**  
   - Содержит поля:
     - `title` (строка, заголовок)
     - `description` (строка, описание)
     - `priority` (целое, приоритет)
     - `dueDate` (строка, формат `YYYY-MM-DD`)
     - `status` (перечисление: `TODO`, `IN_PROGRESS`, `DONE`)
   - Поддерживает сериализацию и десериализацию через `to_json`/`from_json`.

2. **Класс `TaskManager`** (обёртка над `std::vector<Task>`)  
   - Методы:
     - `addTask(const Task&)` — добавить новую задачу
     - `removeTask(size_t index)` — удалить задачу по индексу (с проверкой границ)
     - `updateTask(size_t index, const Task&)` — заменить задачу
     - `template<typename Compare> sortTasks(Compare cmp)` — сортировка по любому полю через лямбду
     - `saveToFile(const std::string& filename)` — сохранить все задачи в JSON-файл
     - `loadFromFile(const std::string& filename)` — загрузить задачи из JSON-файла (перезаписывает внутренний вектор)
   - Инкапсулирует логику валидации индексов и сериализации.

3. **Консольный интерфейс (до GUI-расширения)**  
   - Точка входа `src/main.cpp` (до GUI-версии) предоставляла текстовое меню:
     ```
     1. Добавить задачу
     2. Удалить задачу
     3. Обновить задачу
     4. Показать все задачи
     5. Сортировать задачи
     6. Сохранить в файл
     7. Загрузить из файла
     0. Выход
     ```
   - Обработка ввода через `std::getline`/`std::cin`, лямбды для сортировки.

4. **Графический интерфейс (Qt Widgets)**  
   - Классы и файлы:
     - `src/gui/MainWindow.h` / `MainWindow.cpp` — окно на базе `QMainWindow`
     - Внутренности:
       - `QListWidget` для отображения списка задач
       - `QPushButton` для “Добавить”, “Удалить”, “Редактировать”, “Сохранить”, “Загрузить”
       - Слоты, вызывающие методы `TaskManager` и обновляющие `QListWidget`
   - При запуске приложение автоматически загружает `tasks.json`, если он существует, затем показывает текущее состояние.
   - Данные собираются через `QInputDialog` (заголовок, описание, приоритет, дедлайн, выбор статуса из выпадающего списка).
   - При сохранении/загрузке появляется всплывающее окно (`QMessageBox`) с подтверждением.
